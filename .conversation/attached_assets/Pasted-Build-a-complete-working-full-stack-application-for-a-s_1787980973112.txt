Build a complete working full-stack application for a software internship technical assessment titled:

“AI-Powered Image Quality & Defect Detection”

IMPORTANT CONSTRAINTS:

* This is an offline/local AI application.
* Do NOT use OpenAI, Gemini, Claude, Google Vision, AWS Rekognition, or any external AI/vision API.
* No API keys should be required.
* The AI decision component must use a real machine-learning model, not only OpenCV threshold rules.
* Prioritize a working, reproducible application over unnecessary complexity.

TECH STACK:

* Frontend: React + Vite
* Backend: Python + FastAPI
* Computer Vision: OpenCV + Pillow + NumPy
* Machine Learning: scikit-learn
* Model: RandomForestClassifier using engineered image-quality features
* Database: SQLite
* Model persistence: joblib
* Containerization: Docker + Docker Compose

APPLICATION GOAL:
A user uploads an image. The application analyzes its visual quality and returns:

* quality score from 0–100
* quality label: ACCEPTABLE, DEGRADED, or POTENTIALLY_DEFECTIVE
* detected issues
* severity for each issue
* confidence for each issue
* image-quality statistics
* explainability information

REQUIRED DETECTION CAPABILITIES:

1. Blur / insufficient sharpness
2. Underexposure
3. Overexposure
4. Image noise
5. Image corruption or severe degradation
6. Potential visual defect

AI/ML REQUIREMENT:
Implement a genuine ML pipeline.

Use engineered image features such as:

* Laplacian variance / sharpness
* mean brightness
* brightness standard deviation / contrast
* noise estimate
* saturation statistics
* edge density
* texture-related statistics
* histogram-based features where useful

Create a training pipeline that can generate controlled degradations from clean images:

* blur
* underexposure
* overexposure
* Gaussian noise
* JPEG/degradation corruption

Train a RandomForestClassifier on the extracted features.

IMPORTANT:
The application must be able to work even if a pre-trained model file does not initially exist. Create a practical training script that generates a small reproducible synthetic training dataset from sample/clean images and trains the model.

Use a fixed random seed for reproducibility.

Evaluate the trained model using:

* accuracy
* precision
* recall
* F1-score
* confusion matrix

Save evaluation results in a clear format that can be documented in README.

Do NOT fabricate evaluation metrics. If the model has not actually been trained yet, provide a training command/script that generates the real metrics.

BACKEND:
Create FastAPI REST endpoints:

GET /health

* return HTTP 200 and service/model status

POST /api/analyze

* accept an uploaded image using multipart/form-data
* validate file type
* validate that the image can actually be decoded
* handle invalid/corrupt images gracefully
* extract image features
* run ML inference
* calculate quality score and label
* determine issue severity/confidence
* save analysis result to SQLite
* return structured JSON

GET /api/history

* return previous analyses

GET /api/history/{id}

* return one analysis

Use appropriate HTTP status codes and useful error messages.
